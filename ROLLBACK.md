# ClawPanel: откат

1. Остановите только `clawpanel.service` через `systemctl --user stop`
   под пользователем службы. Gateway и Docker не останавливайте.
2. Сохраните новый каталог под отдельным диагностическим именем, не удаляя
   его. Верните прежний полный каталог на `/opt/openclaw/clawpanel` с
   исходными владельцем и правами; не смешивайте старый `dist/` с новым API.
   Если резервный каталог недоступен, используйте проверенную копию из
   [бэкапа](BACKUP.md).
3. Запустите только `clawpanel.service`. Проверьте health, вход и `/ws`,
   Web Assistant и Dashboard.
4. Не восстанавливайте конфигурацию, базы, сессии или данные браузера
   автоматически: это может затереть работу после переключения. При
   подтверждённом повреждении согласуйте отдельное восстановление,
   предварительно сохранив текущее состояние и проверив целостность копии.
