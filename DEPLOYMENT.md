# ClawPanel: ручное обновление

Выполнять только после отдельного разрешения. Сначала выполните и проверьте
[бэкап](BACKUP.md); держите под рукой [план отката](ROLLBACK.md).

1. В новом каталоге на том же файловом разделе, но не внутри
   `/opt/openclaw/clawpanel`, получите `integration/clawpanel-custom` из
   `egopimpom/clawpanel` и выберите точный проверенный коммит. Под Node версии,
   поддерживаемой проектом, выполните `npm ci`, `node --test tests/*.test.js`
   (при необходимости `PYTHON=/usr/bin/python3`) и `npm run build`.
   Подготовьте весь каталог: `dist/`, `scripts/`, исходные модули и
   зависимости должны соответствовать одному коммиту.
2. До переключения проверьте комплект на loopback-порту с отдельными HOME,
   конфигом, состоянием и тестовым Gateway. Не подключайте такой экземпляр
   к пользовательским данным. Для Web Assistant требуется пароль панели;
   внешние провайдеры с ключом должны использовать HTTPS. Для env/SecretRef
   зарегистрируйте тот же ключ и origin провайдера в OpenClaw
   `models.providers`. Сохраните рабочий allowlist, не расширяя его.
3. В согласованное окно под пользователем службы остановите **только**
   `systemctl --user stop clawpanel.service`. Переименуйте старый каталог
   приложения в заранее выбранный уникальный резервный путь и переместите
   подготовленный каталог на `/opt/openclaw/clawpanel`. Wrapper и unit уже
   используют этот путь. Не заменяйте только `dist/` и не меняйте каталоги
   данных, Gateway или Docker.
4. Выполните `systemctl --user start clawpanel.service`. Проверьте
   `http://127.0.0.1:1420/__api/health`, вход с привычного URL и подключение
   `/ws`. В тестовой сессии проверьте первый ответ и смену модели, Web
   Assistant с разрешённым провайдером и стриминг, отображение списка агентов
   на Dashboard, Workspace и Hosted Agent, grouped/flat, аватары и галерею.
   Сверьте PID и время запуска Gateway до и после: он не должен перезапускаться.

Любой сбой запуска или критическая регрессия — повод использовать
[откат](ROLLBACK.md), а не менять Gateway или восстанавливать данные наугад.
